Teacher should show students how to present a portfolio of the work that they have done in the practical sessions. Whilst students have done this in pairs or threes, each student will be expected to submit their own portfolio of worksheets.

Teachers should also prepare students for the project work that is to come.

Students have a choice of projects:

Project 1: Build a transformer

Use laminations and copper wire to build a transformer of your choice.

Add a rectifier circuit and a capacitor

Devise a test rig with resistors and measure the performance of your power supply.

Project 2: Create a personal electric vehicle

Specify and build a personal electric vehicle. The vehicle should achieve set speed, and torque, It should be capable of travelling for a set number of kilometers with a given battery life.

For all projects students should create

  • A proposal
  • A plan
  • A test document
  • A description of the project and how it went
  • Diagrams test results
  • A discussion of how AI was used to help in the project and how the AI was verified

Students should carry out the project in pairs
