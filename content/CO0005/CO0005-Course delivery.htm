How much learning is there?

This course is 60 Guided Learning Hours - GLH.

Students are expected to spend an additional 30 learning hours on homework giving a Total Qualification Time - TQT - of 90 hours. The GLH consists of lectures, tests, practical sessions and project work.

How is the course put together?

Matrix courses consist of many media objects: Spreadsheets, small pieces of text, worksheets, videos, PowerPoints etc.

These appear in a sequence inside a browser.

The sequence and content of these objects is dictated by a Definition spreadsheet.

Much of the content is presented in small html files. These are defined in a single Content Word, or Google Docs, file.

How can the course content be changed?

The course is fully editable: by altering the Content file and the Definition file the content and structure of the course can be changed.

Similarly new courses can be assembled simply by copying and pasting content into new Definition spreadsheet and Content document.

How is the course used?

This course has been created by Matrix TSL to show how their equipment can be used to deliver a course in Electrical Machines.

This is primarily a planning tool for teachers:

  • It allows them to organise a course based on a Scheme of Work - the Definition spreadsheet.
  • It allows them to define lesson plans as part of the scheme of work
  • It allows them to organise the worksheets that manage practical activities
  • It allows them to map the syllabus to the Scheme of Work

The course is teacher centred. It can also be presented as it is to students to show them the course ahead of them. Or a student version can easily be created from it.

SCORM compliance

Many institutions have a Learning Management System like Moodle or Blackboard. The content of this course is compatible with these systems through the SCORM standard. A SCORM file containing all of the assets in this course can be downloaded and inserted into any SCORM compatible LMS.
