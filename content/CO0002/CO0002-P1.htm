Project

This is a chance for you to develop a project of your own which proves your capability. You should discuss this with your teacher.

Design brief:

Think of a project that you would like to carry out. It should be something you are interested in and would ideally be a real engineering project involving the touch screen display, inputs and outputs, and perhaps a real world sensor connected to a mechanical system like a pump, a strain gauge sensor etc. Include a list of the technical risks in the project – what don’t you know? What are the areas of difficulty? How will you overcome these difficulties? What do you need to learn?

Discuss the project with your teacher before you start.

Create a full design brief with sketches of the panel, the hardware, the software, and a sketch of the Colour touch screen display graphics if this is used. Planning is important.

Hardware:

Use E-blocks boards as the heart of your project. Use the prototype board if you need additional circuitry. Use the Engineering sensors or any third party sensor. Create the hardware.

Software

Create the software

Test

Show how you have tested your project.

Write up and presentation

Modify your Design brief to create a report on your project with the test results. Create and deliver a presentation to the class on your project.
