How to add a course

Everything lives in Google Drive. Add a folder, its files and a definition, click Sync from Drive now, and the course publishes to the site — usually in a couple of minutes.

A course is three things in Google Drive: a folder (named with the course code), the content files inside it, and a definition that lists the screens in order. Add those, then sync. New CO/CP courses publish automatically — no hidden switches.

The 6 steps

1

Create the course folder in Google Drive

In the shared Drive LMS Project Assets, make a new folder named with the course code and title, for example CO0010 - Fire Safety Basics.

  • The code is two letters + four digits at the very start of the name — that's how the system recognises a course.
  • Use CO… for a full course (gets a certificate) or CP… for a worksheet pack (no certificate).
  • Only CO and CP codes publish automatically — other codes (like a ZZ… test) are held back on purpose.

💡 Fastest start: duplicate the TEMPLATE folder and rename it — the structure is ready-made.

2

Add the content files

Drop the screen files into the folder — worksheets (.docx), images (.png/.jpg/.svg), PDFs, and HTML pages. They can sit in the folder root or a media/ subfolder; the whole folder is scanned.

You can also author a screen straight from a Google Doc/Sheet/Slides — the sync exports it to .docx/.xlsx/.pptx automatically.

3

Add the definition

The definition is a small table that lists the screens, one row each, in order. Name it with “definition” in the title, e.g. CO0010 - definition. It can be either:

  • a Google Sheet, or
  • an uploaded Excel .xlsx file — both work, so use whichever you prefer.

See the definition sheet below for the exact columns.

4

Add a row to Course_structure

Open the Course_structure sheet in the Drive root and add a row for the course. This drives the catalogue card — its section, description and search. See Course_structure below. (Optional — skip it and the course still appears, using the folder name.)

5

Sync from Drive

Go to the Admin dashboard and click 🚀 Sync from Drive now. It pulls everything from Drive, matches each file, and publishes — usually 1–2 minutes, then the page refreshes. (It also syncs automatically every ~5 minutes.)

6

Check it's healthy

The course now appears on the Courses page. The Admin dashboard shows its health — every screen should read ✅ Displays. If any say ❌ Missing, see Troubleshooting.

The definition sheet — columns

One row per screen, in the order they should appear. A header row names the columns (they can be in any order):

ColumnWhat it is
Screen typeHow the screen is shown — see screen types.
TitleThe screen's name in the sidebar. (If blank, it's derived from the file name.)
FileThe file for this screen — see below.
HoursGuided learning hours for the screen (used to total the course time). Optional.
EquipmentAny kit needed. Optional — shown as a note.

What goes in the “File” column

  • Just the file name as it is in the folder — intro.docx.
  • Or the full Drive path — LMS Project Assets/CO0010 - Fire Safety Basics/intro.docx.
  • Or a web link for a YouTube/external screen — https://youtu.be/….

Matching is forgiving: it ignores case, hyphen-vs-en-dash “–”, and .htm/.html differences. So a small typo still finds the right file — but the file must actually be in the folder.

Course_structure — the catalogue card

One row per course in the Course_structure sheet (Drive root). It controls how the course appears on the Courses page:

ColumnDrives
Course codeWhich course the row belongs to (e.g. CO0010).
Course titleThe card + page title.
Course typeWhich section it's grouped under (Student-centred, Teacher-centred, CPD, Worksheet packs).
KeywordsExtra words the search box matches.
DescriptionThe short blurb on the card.
Number of sheets / Hours of learningShown on the card (fall back to the live totals if blank).

A blank cell never wipes good data — it keeps whatever was there before, so partial edits are safe.

Hiding a work-in-progress

New CO/CP courses publish by default. To keep one off the site while you build it, add a settings row above the header in its definition:

Activeno

Set Active: no (or draft/hidden) to hold it back; set Active: yes or remove the row to publish. Held-back folders are listed in the Admin dashboard so you always know what's waiting.

Troubleshooting — “my course isn't showing”

The Admin dashboard tells you exactly why. The usual causes:

A screen says ❌ Missing

A file named in the definition isn't in the Drive folder. Add the file (exact name) to that folder, or fix the name in the definition, then sync. The site never shows a stale copy — a missing file honestly reads “missing” until the real one is added.

The whole course isn't on the Courses page

  • No definition found — add a Google Sheet or Excel file with “definition” in its name.
  • Held back — Active: no — its definition is marked not-live; set Active: yes or remove that cell.
  • No screen rows yet — the definition has a header but no rows; add at least one.
  • Not a CO/CP code — only CO/CP codes publish automatically; rename the folder.

Every one of these is listed for you in the Admin dashboard under “Drive folders not yet on the courses page”, each with the fix — so it's never a mystery.
