How to add a course

A course is three things in Google Drive: a folder named with the course code, the content files inside it, and a definition that lists the screens in order. Add those, then sync. CO and CP courses go live on their own.

How it works

You only ever touch Google Drive. Everything after that runs on its own.

The 6 steps

1

Create the course folder from the template

The TEMPLATE: Course structure folder in LMS Project Assets has the three pieces every course needs: a media folder, a definition spreadsheet, and a welcome.html page.

⚠️ Google Drive can't copy a whole folder. Build yours from the template's parts:

  1. In LMS Project Assets, create a new folder.
  2. In TEMPLATE: Course structure, right-click the definition spreadsheet and pick Make a copy. Move the copy into your folder. Do the same for welcome.html.
  3. Add a media subfolder for the content files.

Name the folder with the course code and title, like CO0010 - Fire Safety Basics.

  • The code is two letters and four digits at the start of the name. That's how the system spots a course.
  • CO is a full course with a certificate. CP is a worksheet pack without one.
  • Only CO and CP folders go to the site. Anything else, including the template, is ignored.
2

Add your content files

Put your files in the media folder: worksheets (.docx), images, PDFs, HTML pages. The whole folder is scanned, so the root works too. You reference each file by its name.

A file becomes a screen once you list it in the definition (Step 3). Copy the pattern from the template's definition, or any existing course's.

You can also author a screen as a Google Doc, Sheet, or Slides. The sync exports it to .docx, .xlsx, or .pptx.

3

Add the definition

The definition is a small table: one row per screen, in order. You copied the template's version in Step 1, so just edit its rows. Give it a name with “definition” in it, like CO0010 - definition. It can be:

  • a Google Sheet, or
  • an uploaded Excel (.xlsx) file. Both work.

See the definition sheet below for the columns.

4

Add a row to Course_structure

Add a row for the course to the Course_structure sheet in the Drive root. It sets the catalogue card: section, description, and search. This is optional. Skip it and the course still appears under its folder name.

5

Sync from Drive

On the Admin dashboard, click 🚀 Sync from Drive now. It pulls from Drive, matches each file, and publishes in a minute or two. It also syncs on its own every 5 minutes.

6

Check it's healthy

The course appears on the Courses page. The Admin dashboard shows its health. Every screen should read ✅ Displays. For any ❌ Missing, see Troubleshooting.

The definition sheet

One row per screen, in order. A header row names the columns. They can be in any order.

ColumnWhat it is
Screen typeHow the screen shows. See screen types.
TitleThe screen's name in the sidebar. Blank uses the file name.
FileThe file for this screen. See below.
HoursGuided learning hours. Optional. Totals the course time.
EquipmentAny kit needed. Optional. Shown as a note.

What goes in the “File” column

  • The file name as it is in the folder: intro.docx.
  • The full Drive path: LMS Project Assets/CO0010 - Fire Safety Basics/intro.docx.
  • A web link for a YouTube or external screen: https://youtu.be/….

Matching ignores case, hyphen vs en-dash “–”, and .htm vs .html. A small typo still finds the file. The file just has to be in the folder.

Course_structure

One row per course, in the Course_structure sheet in the Drive root. It sets how the course looks on the Courses page.

ColumnDrives
Course codeWhich course the row is for, like CO0010.
Course titleThe card and page title.
Course typeThe section it sits under: Student-centred, Teacher-centred, CPD, or Worksheet packs.
KeywordsExtra words the search box matches.
DescriptionThe short blurb on the card.
Number of sheets / Hours of learningShown on the card. Blank uses the live totals.

A blank cell never wipes good data. It keeps what was there before.

Hiding a draft

CO and CP courses publish by default. To keep one off the site while you build it, add a settings row above the header in its definition:

Activeno

Active: no (or draft, or hidden) holds it back. Active: yes, or removing the row, publishes it. Held-back folders show in the Admin dashboard.

Troubleshooting

The Admin dashboard tells you why. The usual causes:

A screen says ❌ Missing

A file named in the definition isn't in the Drive folder. Add it under the exact name, or fix the name in the definition, then sync. The site never shows a stale copy. It reads “missing” until the real file is there.

The whole course isn't on the Courses page

  • No definition found. Add a Google Sheet or Excel file with “definition” in its name.
  • Held back. Its definition says Active: no. Set Active: yes or remove that cell.
  • No screen rows yet. The definition has a header but no rows. Add at least one.
  • Not a CO or CP code. Rename the folder.

The Admin dashboard lists each of these under “Drive folders not yet on the courses page”, with the fix.
