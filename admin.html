📚 How to add a course

Everything lives in Google Drive. A course = a Drive folder + a definition sheet + a row in Course_structure. Add those, click Sync from Drive now, and it publishes to the site.

1

Create the course folder in Google Drive

In the shared Drive (LMS Project Assets), make a new folder named with the course code and title, e.g. CO0010 - Fire Safety Basics. The code is two letters + four digits.

2

Add the content files

Put the screen files in that folder — worksheets (.docx), images (.png/.jpg), PDFs, etc.

3

Create the definition sheet

Add a Google Sheet named <CODE> - definition (e.g. CO0010 - definition). One row per screen, in order:

Screen TypeTitleFileHoursEquipment
worksheetIntro to Fire Safetyintro.docx0.5
imageExtinguisher chartchart.png0.2
youtubeSafety demohttps://youtu.be/…0.3

Screen Type accepts: worksheet / document · image · pdf · youtube · spreadsheet · powerpoint · html. File is just the filename in the folder (or a full URL for YouTube).

4

Add a row to the Course_structure sheet

Open the Course_structure sheet and add a row: Course Code, Course Title, Course Type, Number of Sheets, Hours of Learning, Keywords, Description. This drives the course card — its grouping, description and search.

5

Sync from Drive

Back on this page, click 🚀 Sync from Drive now (top of the dashboard). It pulls everything from Drive and publishes to the site — takes ~1–2 minutes, then the page refreshes. (It also syncs automatically every ~5 minutes.)

6

Check it’s healthy

The course now appears on the Courses page. This dashboard shows its health — every screen should read ✅ Displays.

If a screen shows ❌ Missing after syncing, a filename in your definition sheet doesn’t match a file in the Drive folder. Fix the name (in the sheet or on the file) and sync again. Matching forgives case, hyphen-vs-en-dash and .htm/.html.
