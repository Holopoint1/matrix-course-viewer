    How editing works

    Pick a course on the left to edit its details, screens, and the on-screen text, images and links learners see.

    It's live — straight to the database

    This editor reads from and writes to a Supabase database. Every change you make is saved directly to that database for everyone, instantly — there is no publish step and no developer involved. The public Course Viewer reads the same database, so learners see your changes almost immediately (a quick auto-refresh). Edit a course → it's live. The status pill at the bottom-right confirms each save (Saving… → Saved ✓ live to database).

    ⚠ Please read before editing

    • Changes are immediate and shared. There is no draft or per-user copy — what you type is the live course for all users as you save it.
    • There is no “undo” / “reset”. The old reset buttons were removed because edits now go straight to the live database. To recover, you'd re-enter the content (or restore from a download).
    • Open access right now. There is currently no login — anyone with this page's link can make changes. Restricted logins are planned; until then, treat this page as sensitive and don't share the link widely.
    • Back up before big changes. Grab a full copy any time from Tools → Database → Download (courses.json, screens.json, pages.json + every page's HTML).
