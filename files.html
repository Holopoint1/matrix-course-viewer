SCORM 1.2 package

Wraps a course's content into a self-contained SCORM 1.2 package (SCO) — imsmanifest.xml, the viewer, the SCORM API bridge, filtered data and all referenced content — ready to drop into any SCORM-compliant LMS (Moodle, Canvas, etc.). Same structure as the build script. (This is Hamed's area — flag him if the SCORM runtime needs changes.)

Live folder

Google Drive folder

Open the shared course Drive folder in a new window (you sign in to Google there as normal — nothing is stored here). Paste a different folder link to switch folders.

The inline view only renders if the folder is shared “Anyone with the link”. If it stays blank, use Open in new window.
