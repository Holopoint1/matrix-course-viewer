Split a Course content document

What this does: breaks one big tagged Word document into the individual worksheet / page / document files the course viewer uses. Drop here: the course's Course content.docx — the tagged source containing <worksheet>, <HTML>, <document> blocks with <filename> (this is the content doc, not the definition). Optionally add the course's Media folder so images embed into every output. Nothing is deleted — re-running only replaces duplicate files.

Live content database

Database & course downloads

Course content (every screen's text, images and links) lives in a Supabase database — not in flat files. Editors change it in the Admin section; saves apply instantly for everyone, with no redeploy and no developer. The public site reads from the database (and safely falls back to the built-in copy if the database is ever unreachable).

Use the buttons below to pull the current, amended courses out as files — for big offline restructuring, a backup, or handing to someone. This is read-only: it downloads, it never changes the live courses.
